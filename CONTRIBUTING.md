# Como contribuir

Obrigado por querer ajudar no HA Turing Screen!

## Antes de começar

- Confira as issues existentes para evitar duplicatas.
- Para mudanças grandes, abra uma issue descrevendo a proposta antes de começar.
- Nunca envie `ha_screen.ini`, tokens, credenciais ou dados pessoais.

## Fluxo sugerido

1. Faça um fork do repositório.
2. Crie uma branch para sua alteração (`feat/nova-funcionalidade` ou `fix/correcao`).
3. Faça mudanças pequenas e objetivas.
4. Execute `python -m py_compile ha_screen.py` e teste o painel quando tiver o hardware disponível.
5. Abra um Pull Request explicando o que mudou e como foi testado.

## Relatos de bugs

Inclua a versão do Python, a revisão da tela (A/B), os passos para reproduzir e a mensagem de erro sem informações sensíveis.
